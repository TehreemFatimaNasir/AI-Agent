# 🛡️ Legal Shield AI

**Legal Shield** is an AI-powered legal document assistant built with **Streamlit, Agno, and Google Gemini**. It allows users to upload a contract PDF and interact with an AI assistant to understand the contract, identify risky clauses, and get suggestions for improving unfair terms.

---

## ✨ Key Features

> ### 🚀 What Legal Shield Can Do

* 📄 **Upload Contract PDFs** — Upload any contract in PDF format.
* 🤖 **AI Contract Analysis** — Analyze contracts using Google Gemini.
* 📝 **Contract Summarization** — Get a simple and easy-to-understand summary.
* ⚠️ **Risk Detection** — Identify risky, unfair, or suspicious clauses.
* 💡 **Suggest Fixes** — Get suggestions for improving problematic clauses.
* 📚 **Explain Legal Terms** — Understand difficult legal terminology in plain English.
* 💬 **Ask Questions** — Chat with the AI about your uploaded contract.
* ⚡ **Quick Actions** — Quickly choose **Summarize**, **Find Risks**, or **Suggest Fixes**.
* 🎨 **Professional UI** — Custom dark navy and silver legal-themed interface.
* 🔐 **Secure API Key Handling** — API keys are stored using environment variables.

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/TehreemFatimaNasir/AI-Agent.git
```

```bash
cd AI-Agent
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 🔑 Configure Google Gemini API

Create a `.env` file in the root directory:

```env
GOOGLE_API_KEY=your_google_gemini_api_key
```

###  Important

Never upload your `.env` file or API key to GitHub.

Make sure `.gitignore` contains:

```text
.env
__pycache__/
*.pyc
```

---

## ▶️ Run the Application

```bash
streamlit run main.py
```

The application will open in your browser.

---

## 🧠 How It Works

1. **Upload Contract**
   Upload a PDF contract through the application.

2. **Extract Text**
   The application extracts text from the uploaded PDF using `pdfplumber`.

3. **AI Agent**
   An Agno AI Agent powered by Google Gemini analyzes the contract.

4. **Contract Analysis**
   Users can use quick actions:

   * Summarize
   * Find Risks
   * Suggest Fixes

5. **Ask Questions**
   Users can ask any question about their uploaded contract through the AI chat.
